# 게시글 템플릿

콘텐츠 폴더마다 `posts.md`로 복사해 채운다. 순서: 질문 훅 → 장면 → 다녀온 분들 이야기(쿠팡 후기) → 가기 전에(사기 전에) → 링크 안내.
요약 목록이 아니라 이야기로 쓴다 (2026-11-10). 장면은 보는 사람이 거기 있는 것처럼 「~할 수 있어요」「~가 열려요」로, 상품 페이지 사실만. 후기는 「쿠팡 후기를 보니 다녀온 분들 ~래요」처럼 풀고 **개수를 쓰지 않는다** — 전부면 「모두」, 절반 넘게면 「~는 얘기가 많았어요」, 그보다 적으면 「~라는 후기도 있어요」. 개수는 「확인할 것」에. 「(상품 페이지 기준)」「(쿠팡 후기)」 같은 괄호 표시도 쓰지 않는다 — 후기 출처는 「쿠팡 후기 보니」처럼 문장 안에 (2026-11-10). 「저는 가 봤어요」 같은 경험담은 쓰지 않는다.
`{…}`는 채울 자리다. 상품 페이지·캡처로 확인된 사실만 쓴다. 가격·할인율·기간은 본문에 넣지 않고 맨 아래 「확인할 것」에 둔다.
쿠팡 파트너스 고지는 게시글과 키티챗 DM에 넣지 않는다 — 영상(첫·마지막 장면)과 카드뉴스(첫·마지막 장) 안에 있다 (2026-11-09, CLAUDE.md §3).

## 링크 안내 (2026-11-06)

| 플랫폼 | 링크 안내 |
| --- | --- |
| 인스타그램 | 댓글 키워드 → 키티챗이 DM으로 링크 + 프로필 링크 No. |
| 틱톡 | 프로필 링크 No. |
| 유튜브 | 제휴 링크를 아직 못 달았다 → 인스타 @hikary.vibe 프로필 링크 No. |

- No.는 인포크링크 번호로, 상품마다 하나다. 첫 포스팅만 사람이 알려주고, 그 뒤로는 운영대장 메모에서 가장 큰 No.에 1을 더한다. 사람은 그 번호로 인포크링크에 추가한다.
- 키워드는 상품을 한 단어로 (예: 시계, 아쿠아리움). 키티챗은 모든 댓글에 DM을 보내도록 설정한다 (2026-11-09) — 게시글의 「'키워드' 남기면」 안내는 그대로 써도 된다. 퀴즈면 키워드가 정답을 드러내지 않게 고른다. 팔로우를 조건으로 걸거나 경품·자료 같은 보상을 약속하지 않는다. 약속한 DM은 실제로 보낸다.

## 인포크링크

- 연결할 주소: `{쿠팡 파트너스 링크}` (사람이 만듦 → 같은 상품으로 가는지 확인)
- 타이틀: `No.{번호} {상품 이름}`
- 이미지: `inpock.png` (1080×1080, 실제 상품 사진 + No. 배지)

## 인스타그램 (릴스 · 캐러셀)

첫 줄(훅)이 「더 보기」 전에 보이니 짧게 쓴다.

```
{보는 사람 상황 질문}? {이모지}

{장면 2~3줄 — 「~하다가 ~까지 할 수 있는 {분류}예요」}
{장면 한 줄 더} {이모지}

쿠팡 후기를 보니 다녀온 분들 {모두 / 많이} {가장 많이 나온 말}래요.
{두 번째로 많이 나온 말}는 얘기도 많았어요.
{적게 나온 말}는 후기도 있어요.

✔ 가기 전에
· {사실 1}
· {사실 2}

💬 댓글에 '{키워드}' 남기면 DM으로 링크 보내드려요
(DM이 안 보이면 메시지 요청함을 확인해 주세요)
📌 프로필 링크 No.{번호}에서도 바로 볼 수 있어요
💾 필요할 때 꺼내 보게 저장해 두세요

#{상품} #{분류} #{상황} #{대상} #{용도}
```

## 키티챗 (인스타 댓글 → DM)

인스타에 올린 뒤 키티챗에서 그 게시물에 연결한다. 키워드는 게시글 💬 줄과 같게 쓴다. 문구와 링크 사이는 한 줄 띄운다 (2026-11-09).

- 키워드: `{키워드}`
- DM 문구:

```
요청하신 {상품 이름} 링크예요 👇

{쿠팡 파트너스 링크}
```

- 무료 요금제: 월 500건, DM에 키티챗 광고가 붙는다. 무료에서 키워드 조건이 되는지는 확인 필요.

## 유튜브 쇼츠

제목 (100자 이내): `{상황 질문 — 퀴즈면 「…, 어디게?」} #{해시태그} #{해시태그} …` — 해시태그는 제목에 넣고 설명에는 넣지 않는다. `#shorts`는 쓰지 않는다 (세로 영상이면 유튜브가 쇼츠로 분류한다, 2026-11-09).

설명:

```
{보는 사람 상황 질문}?

{장면 2~3줄 — 인스타와 같게}

쿠팡 후기를 보니 다녀온 분들 {모두 / 많이} {가장 많이 나온 말}래요.
{두 번째로 많이 나온 말}는 얘기도 많았어요.

✔ 가기 전에
· {사실 1}
· {사실 2}

📌 상품 링크는 인스타 @hikary.vibe 프로필 링크 No.{번호}에서
```

```
#{상품} #{분류} #{상황} #{대상} #{용도}
```

## 쓰지 않는 말

- 써 본 것처럼: 「힐링 되는 기분이에요」, 「쾌감 폭발」, 「제가 써 보니」
- 확인 안 된 과장: 「끝판왕」, 「인생템」, 「180도」, 「마법」, 「정석」, 「최저가」, 「품절 임박」
- 후기 키우기: 한 명만 한 말을 「다들」, 「제일」로
- 팔로우 조건, 경품·자료 같은 보상

## 확인할 것 (본문에 넣지 않음)

- 가격·할인율·기간: {값} ({날짜} 기준)
- 후기 근거: {어디서} {몇 개 중 몇 개}, 뺀 후기와 이유
- 인포크링크 No.{번호} · 인스타 키워드 '{키워드}'
- 그 밖에 확인 필요한 것
