04 쇼츠 제작안 만들기

설명과 선택한 이미지에서 핵심 매력·약 18초 대본·4컷 구성·게시글을 만듭니다.

메모는 제작안 생성 때만 참고하고 시트에 저장하지 않습니다.

컷별 대사를 수정하면 전체 대본도 갱신됩니다. 전체 대본을 직접 수정했다면 아래 컷별 대사도 확인해주세요.

플랫폼별 게시글 · 업로드 상태

05 4컷 제작안 · 영상용 이미지

컷별 사진과 대사·후반 자막·연출을 수정하세요. 영상은 생성하지 않으며, 선택한 사진과 제작안으로 후속 편집을 준비합니다.

제작안 텍스트는 대본 칸에 함께 저장됩니다. 이미지 파일은 저장하지 않으므로 로컬에 내려받아 보관하세요. 다음 접속에서 사진을 다시 추가·선택할 수 있습니다.

06 로컬 영상 제작

4컷 사진과 JSON을 같은 폴더에 내려받은 뒤 Windows ffmpeg 도구로 MP4를 만듭니다. 자막은 넣지 않습니다. 음성 생성은 별도 선택이며 자동 게시하지 않습니다. 기본 영상은 컷 전환과 느린 확대를 사용하고, 자유 입력한 연출 문장을 자동 실행하지 않습니다.

검토 후 저장하면 업로드 관리에 쇼츠로 남습니다.

상품별로 묶어 보여 줍니다. 쇼츠·캐러셀을 열어 고치거나, 올린 뒤 업로드 기록을 남기세요.

서버 연결 설정

콘텐츠 매니저 전용 Apps Script 주소입니다. 기본값을 그대로 쓰면 되고, 접속 코드는 필요 없습니다.

Gemini API 키는 서버(스크립트 속성)에만 있으며 이 화면에 입력하지 않습니다.

업로드 기록

게시물 링크를 넣으면 업로드완료로 저장됩니다.

영상에 쓸 사진 영역 선택

이미지를 스크롤한 뒤 필요한 부분을 드래그하세요. 숫자로 위치와 크기를 조절할 수도 있어요. 자막·가격 안내판보다 실제 사진 영역을 골라주세요.
